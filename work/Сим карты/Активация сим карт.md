#УрАО 
Для активации сим карт нужно использовать госуслуги и идти по этому порядку:

Первым делом подготовить список симкарт для активации. Взять его можно на рабочем столе в папке "**Активация госуслуги**"

1. Зайти в **FireFox**
2. Зайти на **Госуслуги**
3. Нажать **Вход** -> По электронной подписи
4. Выбрать подпись "**ЧОП УрАО**" (Пароль 1-8) (*! ЕСЛИ СИМКА Т2 - Криминалист*)
5. Выбрать пользователя "ЧОП УрАО"
6. Зайти во вкладку "Заявления"
7. Нажать на "Регистрационный акт корпаративных симкарт"
8. Три точки 
9. Действия
10. Об услуге
11. Создать заявление
12. В тех уст...
13. Из файла
14. Загрузить подготовленный файл в csv

Готово. 
Для теле2 нужно дополнительно активировать номер в личном кабинете в интерфейсе.
