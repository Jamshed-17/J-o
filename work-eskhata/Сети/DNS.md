**DNS** - *Domain name system* (Система доменных имён)
Основная цель DNS — это отображение доменных имен в [[IP адрес, маска подсети, шлюз#IP адрес|IP адреса]] и наоборот — IP в DNS. 


## Типы DNS-записей

**Ресурсная запись** — это единица хранения и передачи информации в DNS. Она состоит из полей: имя (Name), тип (Type), класс (Class), время жизни (TTL), длина поля данных (RDLEN) и сами данные (RDATA).

**Основные типы записей:**

| Тип записи | Назначение                                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **A**      | Связывает доменное имя с IPv4-адресом сервера.                                                                                            |
| **AAAA**   | Аналогична записи A, но для IPv6-адресов.                                                                                                 |
| **CNAME**  | Создаёт псевдоним (алиас) для другого доменного имени.                                                                                    |
| **MX**     | Указывает почтовые серверы, которые принимают почту для домена, и задаёт их приоритет.                                                    |
| **NS**     | Определяет DNS-серверы, которые являются авторитетными для зоны.                                                                          |
| **TXT**    | Хранит произвольный текст. Часто используется для хранения настроек SPF, DKIM, DMARC, а также для верификации домена.                     |
| **SOA**    | Служебная запись, которая содержит метаданные о зоне: адрес основного сервера, email администратора, серийный номер и таймеры обновления. |
| **PTR**    | Используется для обратного разрешения: связывает IP-адрес с доменным именем.                                                              |
| **SRV**    | Указывает сервер и порт для определённых служб (например, SIP).                                                                           |

## Роль файла hosts

**Файл hosts** — это локальный текстовый файл, в котором вручную прописаны соответствия доменных имён IP-адресам. Он используется для:

- **Локального тестирования и разработки.** Например, можно добавить запись в файл hosts, чтобы локальный домен указывал на IP-адрес вашего сервера, не обращаясь к публичному DNS.
- **Блокировок.** Можно временно перенаправить доступ к определённым сайтам.
- **Приоритета разрешения имён.** При запросе имени компьютер сначала проверяет файл hosts, и только если там нет нужной записи, обращается к DNS-серверам.
