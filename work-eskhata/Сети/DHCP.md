**DHCP** (англ. Dynamic Host Configuration Protocol – протокол динамической настройки узла) – сетевой протокол прикладного уровня, обеспечивающий предоставление [[IP адрес, маска подсети, шлюз#IP адрес|IP-адресов]] и сведений о сети для хостов, которые хотят подключиться к сети. После получения данных параметров хост становится полноправным узлом сети и может обмениваться пакетами в сети.

Процесс получения настроек устройством обычно описывают аббревиатурой **DORA** (по первым буквам этапов):

1. **Discover (Обнаружение).** Устройство, подключаясь к сети, шлёт широковещательный запрос, ища DHCP-сервер.
2. **Offer (Предложение).** Сервер предлагает устройству свободный IP-адрес и другие настройки.
3. **Request (Запрос).** Устройство подтверждает, что принимает предложенные параметры.
4. **Acknowledgement (Подтверждение).** Сервер окончательно закрепляет за устройством адрес и срок его использования (аренду).

## Как DHCP распределяет IP-адреса

Сервер может использовать три способа:

- **Статическое распределение.** Администратор вручную привязывает MAC-адрес устройства к конкретному IP-адресу. Это удобно для устройств с фиксированными адресами: серверов, принтеров, роутеров.
- **Динамическое распределение.** Сервер выдаёт адрес из пула на определённый срок (аренду). После истечения срока адрес освобождается и может быть выдан другому устройству.
- **Автоматическое распределение.** Новым устройствам адреса выдаются из заданного диапазона на неопределённый срок. При повторном подключении устройство получит тот же адрес.
