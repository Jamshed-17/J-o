## Протоколы
![[Сетевые протоколы]]


TCP (Transmission Control Protocol) и UDP (User Datagram Protocol) — это два транспортных протокола, которые решают одну задачу (передачу данных), но принципиально по-разному. Их ключевое различие в подходе: TCP делает акцент на надёжности, а UDP — на скорости.

|Критерий|TCP|UDP|
|---|---|---|
|**Установка соединения**|Требуется. Используется трёхстороннее рукопожатие (SYN, SYN-ACK, ACK).|Не требуется. Отправитель сразу начинает передачу пакетов.|
|**Гарантия доставки**|Гарантирует доставку каждого байта данных. Если пакет потерян, TCP повторно отправляет его.|Не гарантирует доставку. Потерянные датаграммы не отправляются заново.|
|**Упорядоченность данных**|Гарантирует, что данные будут собраны в правильной последовательности с помощью порядковых номеров.|Не контролирует порядок. Пакеты могут прийти в произвольном порядке.|
|**Контроль ошибок**|Полная проверка целостности через контрольные суммы, повторная передача при ошибках, контроль перегрузки сети.|Минимальная проверка целостности (контрольная сумма), основная задача — быстрая передача.|
|**Накладные расходы**|Большой заголовок пакета (минимум 20 байт).|Минимальный заголовок (8 байт).|
|**Скорость и задержки**|Задержки выше из-за установки соединения и подтверждений. Скорость передачи ниже, но стабильная.|Задержки минимальны. Данные отправляются сразу. Скорость выше, но возможны потери.|
|**Потребление ресурсов**|Требует больше ресурсов для управления соединением и контроля.|Минимальные ресурсы, легковесный протокол.|

## Порты

**Порт** — это логическая конечная точка обмена данными. Порт считается «открытым», когда есть слушающий сокет (процесс привязан к адресу/порту). 

| Порт | Протокол | Служба                                         |
| ---- | -------- | ---------------------------------------------- |
| 20   | TCP      | FTP-DATA (передача данных в активном режиме)   |
| 21   | TCP      | FTP (управление соединением)                   |
| 22   | TCP, UDP | SSH (безопасное удалённое управление)          |
| 23   | TCP, UDP | Telnet (незащищённое удалённое управление)     |
| 25   | TCP, UDP | SMTP (передача электронной почты)              |
| 53   | TCP, UDP | DNS (преобразование доменных имён в IP-адреса) |
| 80   | TCP, UDP | HTTP (веб-трафик)                              |
| 443  | TCP, UDP | HTTPS (защищённый веб-трафик)                  |
| 110  | TCP      | POP3 (приём почты)                             |
| 143  | TCP      | IMAP (синхронизация почты)                     |
| 3306 | TCP      | MySQL (доступ к базам данных)                  |
| 3389 | TCP, UDP | RDP (удаленный рабочий стол Windows)           |
| 5432 | TCP      | PostgreSQL (базы данных)                       |
