#linux #bank 

**DNF (Dandified YUM)** — это современный менеджер пакетов для дистрибутивов Linux, основанных на RPM-пакетах (например, Fedora, RHEL, CentOS, AlmaLinux). 
Он пришёл на смену YUM, решив ряд его проблем: повысил производительность, улучшил разрешение зависимостей и сделал работу с системой более предсказуемой.

## Команды для работы с dnf

| Команда                                  | Что делает                                       |
| ---------------------------------------- | ------------------------------------------------ |
| `install <пакет>`                        | Устанавливает пакет и все его зависимости        |
| `reinstall <пакет>`                      | Переустанавливает пакет                          |
| `check-update`<br>или просто<br>`update` | Проверяет наличие обновлений и обновляет систему |
| `remove <пакет>`                         | Удаляет пакет                                    |
| `list`                                   | Выводит списки доступных и установленных пакетов |
| `search <слово>`                         | Ищет пакеты по ключевому слову в репозиториях    |
| `info <пакет>`                           | Показывает подробную информацию о пакете         |
