#bank 

**HSM - Host security module**

Вся шифровка и дешифровка связанная с банковскими картами происходит в нём. 

- Генерация pin-кодов
- Проверка pin-кодов
- Все операции с CVV

Примечательно, что он не сравнивает отправленный pin код с записью в бд. В HSM к каждому PIN-коду есть алгоритм, который даст этот PIN-код если для расчётов использовать CVV и PIN-блок. Возвращает этот HSM только TRUE и FALSE
