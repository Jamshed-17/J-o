#bank 

CVV - **Card verification value**
Это криптографическая подпись карты. Его главная задача - доказать что во время онлайн покупки карта действительно у клиента в руках. 

Он генерируется процессинговым сервисом с помощью алгоритма шифрования (обычно это Triple-DES). Для вычисления используется:
- PAN
- Срок действия карты
- Сервисный код (код из [[Карты с магнитной полосой |магнитной полосы]])
- Секретный криптографический ключ банка (CVKs)

Существует несколько типов верификационных кодов:
- CVV1/CVC1 - Записан на магнитной полосе. Проверяется когда проводишь картой через терминал
- CVV2/CVC2 - Три цифры на обороте
- Dynamic CVV (dCVV) - Современная технология, когда код меняется каждый час в банковском приложении
