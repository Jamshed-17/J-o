| **Категория ПО**     | **Программа**           |
| -------------------- | ----------------------- |
| **Базовое ПО**       | **BIOS**                |
| **Прикладное ПО**    | **Электронные таблицы** |
| **Сервисное ПО**     | **Архиваторы**          |
| **Инструментальное** | **Нет соответствия**    |

Чтобы правильно распределять программы по категориям, нужно понимать уровень их «близости» к «железу» и их назначение:

1. **Базовое ПО (Системное):** Это программы, без которых работа компьютера невозможна в принципе. Они обеспечивают запуск системы и взаимодействие с аппаратной частью. **BIOS** — это базовая система ввода-вывода, прошитая в материнскую плату, она запускается самой первой.
2. **Прикладное ПО:** Это программы для решения _конкретных пользовательских задач_ (написание текстов, расчеты, игры). **Электронные таблицы** (например, Excel или LibreOffice Calc) — это классический инструмент для работы с данными.
3. **Сервисное ПО (Утилиты):** Это программы, которые расширяют возможности операционной системы, помогают обслуживать компьютер, оптимизировать его работу или выполнять вспомогательные действия. **Архиваторы** как раз являются вспомогательными средствами для управления файлами.
4. **Инструментальное ПО:** Это средства разработки программного обеспечения (компиляторы, интерпретаторы, IDE — среды разработки). Поскольку в списке не было предложено ни одного инструмента для создания кода (например, Python, Visual Studio или компилятор C++), для этой категории верным ответом является **«нет соответствия»**.

Логика:

Классификация ПО — одна из самых частых тем. Используй этот алгоритм проверки:

- **Может ли компьютер включиться и работать без этой программы?** Если нет (или она управляет «железом») — это **Базовое**.
- **Решает ли она мою конкретную задачу (текст, таблицы, фото)?** — это **Прикладное**.
- **Помогает ли она «подлатать», настроить или упорядочить систему?** (антивирусы, архиваторы, драйверы, программы для очистки диска) — это **Сервисное**.
- **Использую ли я её для того, чтобы _написать_ другую программу?** — это **Инструментальное**.

Единица хранения данных на диске в файловой системе объединенная в один или несколько секторов -> Кластер

- **Сектор:** Это минимальная физическая область на диске, которую может прочитать или записать контроллер (обычно 512 байт или 4 КБ). Однако файловой системе «неудобно» работать с такими мелкими кусочками, так как файлов может быть миллионы.
- **Кластер:** Это **логическая единица** хранения данных. Файловая система объединяет несколько физических секторов в один блок — кластер. Когда ты сохраняешь файл, операционная система выделяет под него целое число кластеров. Даже если файл очень маленький, он всё равно займет как минимум один кластер.
- **Дорожка:** Это концентрическое кольцо на поверхности магнитного диска, состоящее из множества секторов. Это физическая структура, а не единица хранения данных для пользователя.
- **Файл:** Это логическая структура данных, имеющая имя, которую _размещают_ в кластерах.
- **Папка (Каталог):** Это специальный файл, в котором хранится «оглавление» (список имён файлов и указатели на то, в каких кластерах эти файлы лежат).
