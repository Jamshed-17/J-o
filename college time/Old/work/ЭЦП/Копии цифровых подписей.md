#УрАО 
Это нужно делать с каждым новым рутокеном. 

1. Отключить интернет (Важно)
2. Взять флешку для копий подписей
3. Открыть папку "**Копирование рутокенов**"
4. Открыть **CertFix** -> найти нужный токен, опознать его
5. Открыть **Token.exe**
6. Открыть Крипто (для просмотра нужного) -> Экспорт
! Формат подписи "Организация сок действия"
7. Открыть **CertFix** -> найти нужный токен (он будет из Fat32)   ->   shift+пкм -> Протестировать ЭЦП
